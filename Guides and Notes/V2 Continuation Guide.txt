Roll20 Action Economy V2 — Continuation Guide

I am building a Roll20 Mod/API script for Jumpgate using the 2024 D&D character sheets. I am rebuilding from scratch because the old script became too patched together.

The new script is called:

ActionEconomyV2
Core design

There are three command families:

!ae

Core action economy, movement, attacks, setup.

!ae-effect

Combat effects like dash, disengage, haste, reckless, concentration, fly, shield, sanctuary, divine favor.

!ae-con

Rules conditions like prone, poisoned, frightened, restrained, stunned, paralyzed, grappled, invisible, etc.

Next development step

The next step is not to add all conditions one by one manually.

The next step is to add a true registry system:

const EFFECTS = { ... };
const CONDITIONS = { ... };

Each entry should contain:

{
  display: "Poisoned",
  marker: "marker id or null",
  duration: "manual | endOfTurn | startOfNextTurn | movement | combat",
  mechanical: "rules reminder text",
  type: "effect or condition"
}

Then build generic functions:

applyEffect(token, effectName)
removeEffect(token, effectName)
applyCondition(token, conditionName)
removeCondition(token, conditionName)

The existing V2 base already has simple versions of these, but they need to be expanded to support markers, duration behavior, and display text.

Duration categories

Use these duration buckets:

endOfTurn

Clears when that token’s turn ends.

Current V2 script limitation

The current V2 base is not final. It does not yet have the full registry or marker system. It has placeholder effects and conditions stores and simple effect/condition handlers.

The next chat should start by reviewing the V2 script and then implementing the registry cleanly.
